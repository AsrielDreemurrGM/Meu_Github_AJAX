<h1>My GitHub AJAX Profile</h1>
<p>
  Este README também está disponível em
  <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  This project is a hands-on exercise in <strong>asynchronous JavaScript</strong>, focusing on fetching and displaying
  GitHub profile information using
  <strong>AJAX</strong> and the <strong>Fetch API</strong>.
</p>
<p>
  🔗 Live Demo: <a href="https://meu-github-ajax-theta.vercel.app" target="_blank">View on Vercel</a>
</p>
<h2>Project Overview</h2>
<p>
  The page retrieves data directly from the GitHub API and dynamically updates the DOM with information such as the
  user’s avatar, name, username, number of repositories, followers, following, and profile link.
  It also includes error handling with <code>catch</code>, providing both console messages and alerts to the user in
  case of API issues.
</p>
<h2>Features</h2>
<ul>
  <li>Fetch API integration for retrieving GitHub profile data.</li>
  <li>Dynamic DOM updates for avatar, name, username, repositories, followers, following, and profile link.</li>
  <li>Error handling with <code>catch</code>, console logs, and alerts.</li>
  <li>Lightweight frontend-only implementation (HTML, CSS, JavaScript).</li>
  <li>Clean and simple structure for practicing asynchronous programming.</li>
</ul>
<h2>Technologies Used</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript (Fetch API, AJAX)</li>
</ul>
<h2>Usage</h2>
<ol>
  <li>Clone the repository.</li>
  <li>Open <code>index.html</code> in a browser.</li>
  <li>The page will automatically fetch and display GitHub profile data.</li>
</ol>
