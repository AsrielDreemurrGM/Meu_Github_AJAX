<h1>Meu Perfil GitHub AJAX</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Este projeto é um exercício prático de <strong>JavaScript assíncrono</strong>, com foco em buscar e exibir
    informações de perfil do GitHub utilizando
    <strong>AJAX</strong> e a <strong>Fetch API</strong>.
</p>
<p>
    🔗 Demonstração: <a href="https://meu-github-ajax-theta.vercel.app" target="_blank">Ver no Vercel</a>
</p>
<h2>Visão Geral do Projeto</h2>
<p>
    A página consome dados diretamente da API do GitHub e atualiza o DOM dinamicamente com informações como:
    <strong>avatar</strong>, <strong>nome</strong>, <strong>nome de usuário</strong>,
    <strong>quantidade de repositórios</strong>, <strong>seguidores</strong>, <strong>seguindo</strong> e
    o <strong>link para o perfil</strong>.
</p>
<p>
    Também inclui tratamento de erros com <code>catch</code>, exibindo mensagens no console e alertas ao usuário
    em caso de falhas na API.
</p>
<h2>Funcionalidades</h2>
<ul>
    <li>Integração com a Fetch API para buscar dados do perfil GitHub.</li>
    <li>Atualização dinâmica do DOM com <code>id</code> e <code>span</code> como placeholders.</li>
    <li>Tratamento de erros com <code>catch</code>, logs no console e alertas.</li>
    <li>Implementação leve apenas com frontend (HTML, CSS, JavaScript).</li>
    <li>Estrutura simples e organizada para praticar programação assíncrona.</li>
</ul>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript (Fetch API, AJAX)</li>
</ul>
<h2>Como Usar</h2>
<ol>
    <li>Clone o repositório.</li>
    <li>Abra o arquivo <code>index.html</code> no navegador.</li>
    <li>A página buscará e exibirá automaticamente os dados do perfil GitHub.</li>
</ol>

<p>
    O histórico de commits documenta o crescimento do projeto passo a passo:
</p>
<ul>
    <li>Upload inicial dos arquivos (<code>index.html</code>, <code>main.css</code>).</li>
